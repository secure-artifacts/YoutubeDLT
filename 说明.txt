使用说明

默认：不勾选“下载整个播放列表” → 只下载单个视频（即使链接带 list=RD... 或普通 playlist）
想下载列表：勾选复选框 → yt-dlp 会下载整个播放列表（或 Radio 中的所有视频）
界面新增了一个复选框，放在质量选择下面，很好找

保存后运行，粘贴你的链接（带 list=RD... 的那个），默认就是只下单个视频了。如果勾选复选框再下载，就会下整个 Radio 列表。

# 1. 先暂存或丢弃本地修改（.gitignore 的修改我们不关心）
git stash
# 2. 强制拉取 GitHub 上最新的 master 分支（覆盖本地）
git fetch origin
git reset --hard origin/master
# 3. 确认已经是最新
git status
git log --oneline -5
# 4. 创建测试 tag 并推送（使用最新的 workflow）
git tag -a v2.0.X -m "Release v2.0.X"
git push origin v2.0.X


正式版本（通过 git tag 推送 v* 或手动触发但不勾选 Debug）→ 只打包并推送正式版
仅当手动触发 workflow_dispatch 并勾选 Debug 时，才额外构建并推送 Debug 版本
